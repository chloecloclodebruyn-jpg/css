# Evidence checklist

## Local browser evidence

1. Open `index.html` in your browser.
2. Confirm Rojo is red, Azul blue, Anaranjado orange, Verde green and Amarillo yellow.
3. Confirm each colour heading has normal font weight and appears above its matching image.
4. Use browser developer tools to confirm each image has computed width and height of 200px.
5. Compare the rendered page with the supplied `goal.png`.
6. Save `01-browser-top.png` and `02-browser-bottom.png` to cover all five colours, or take a full-page screenshot.
7. Save `03-css-source.png` showing the completed stylesheet.
8. Save `04-image-dimensions.png` showing an image's computed dimensions.

## GitHub evidence

After upload, capture the repository file list and upload commit. If publishing with Pages, capture the successful deployment and live page with the address bar visible.

Add the repository URL, commit identifier and optional live website URL to `PORTFOLIO-EVIDENCE.md`.
